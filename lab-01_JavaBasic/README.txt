CACH CHAY CAC BAI JAVA
1. Mo Terminal/PowerShell va di chuyen vao thu muc cua bai muon chay.
2. Bien dich: javac *.java
3. Chay: java TenLop
   Vi du bai 01: java HelloWorld

Moi bai la mot chuong trinh doc lap, khong can tao project Java rieng.
Cac file .java da co dong ghi chu o dau file de mo ta noi dung bai.

LUU Y KHI CHAY CAC BAI FILE/FOLDER
- Bai 07 den 10 co the xoa du lieu that. Chi nhap duong dan cua file/thu muc mau ban muon xoa.
- Bai 11: nhap duong dan thu muc, sau do nhap phan duoi ten, vi du .txt.
- Bai 12: nhap duong dan file nguon va duong dan file dich.
- Bai 13: chay trong thu muc 13_GhiFileNhiPhan de tao sinhvien.dat.
- Bai 14: chay sau bai 13; chuong trinh doc file tu ../13_GhiFileNhiPhan/sinhvien.dat.
- Bai 15: nhap duong dan mot file anh ma may tinh dang co, roi nhap duong dan file PNG dau ra.

Cac bai duoc viet theo huong co ban, khong dung thu vien ngoai.
